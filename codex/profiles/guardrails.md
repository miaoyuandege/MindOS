# Native Agent discipline, not a model profile

This candidate distributes stable workflow constraints, not personal benchmark observations or model recommendations.

- Prefer Root direct for small tightly coupled work.
- Delegate only independent bounded work when the active host/tool policy permits it; default shallow.
- Root integrates and performs final verification. A child saying done is not completion or independent acceptance.
- Requested model/effort and actual Effective evidence are different. Missing values stay UNKNOWN.
- Agent/session count is not cost. Do not sum shared-window usage snapshots into an invoice.
- Do not repeatedly review an accepted baseline without a new delta or Invalidation Evidence.

No fixed agent count, child model, effort ranking or provider cost promise. No automatic routing weights or scheduler. Historical parsing tools help inspect evidence; they do not establish causal performance differences.
