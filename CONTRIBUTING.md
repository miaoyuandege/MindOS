# Contributing

This is a public pre-release test, not a final licensed release. License choice remains pending. No contributor license is implied before the owner selects one. First-divergence installation feedback is the immediate priority.

After a repository is published, welcome contributions are reproducible bug reports, documentation improvements and small focused PRs. Explain the problem, allowed scope, expected behavior and evidence; preserve prior work and run the [affected checks](docs/VERIFY.md). Ask before a broad redesign or new dependency. Do not upload private project files, raw AI sessions, personal profiles, account data or generated history-distiller output. Use synthetic reproductions only.

Submit only material you are entitled to contribute. Identify upstream sources, licenses, changes and attribution requirements for copied or adapted material; AI generation alone does not establish ownership. Report security issues through [the security policy](SECURITY.md), not public issues.

Maintainers do not promise response times, enterprise support, compatibility with untested clients or a roadmap. Acceptance of a report or PR is not a commitment to a feature. Additional templates and community machinery are deferred until useful.
