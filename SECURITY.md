# Security policy candidate

GitHub Private Vulnerability Reporting is enabled for this public pretest (repository API verified 2026-09-04). **Do not post vulnerabilities, credentials, private history or exploit details in public issues.** No response-time guarantee is offered.

Sign in to GitHub and use this repository's Security → Advisories → Report a vulnerability entry for private disclosure. Maintainer notification delivery has not been end-to-end tested. If the entry is unavailable, do not use a public issue as a substitute; contact the maintainer through an already established private channel, if one exists. Do not send a fabricated vulnerability merely to test notifications.

Future private reports should describe the affected candidate version, minimal synthetic reproduction, impact and proposed mitigation. Remove personal paths, account identifiers and secrets. Scope includes source disclosure, unsafe path handling, unintended data export and authorization bypass in shipped tools.

No supported release exists yet. This candidate is experimental, with no enterprise support, guaranteed fix time or automatic credential rotation. Hosting-side controls do not replace local preflight or authorization.

Reference: [GitHub private vulnerability reporting](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository).
