# 执行体系观察

项目 / Stage：

没有新观察时只写：

```text
Execution Experience Delta = NONE
```

有观察才填：

- Wasted Actions：重复读取 Context、恢复 / Full Review、验证已 Accepted 内容、多个 Agent 重复审核？
- Token Waste：搜索未产出价值、报告 / Work Record 过长、确定性动作反复消耗模型？
- Unnecessary Stops：非阻塞问题停止、中断后重复要授权？
- Retry / Rework Cause：失败层级与 AI 自造返工，引用真实 Evidence。
- Useful Rules：真实减少成本的规则。
- Tool / Agent Value：工具 / Skill / Agent 实际收益，而非数量。
- Candidate Improvement：看似先进但增加摩擦的规则、最小改进候选；不自动授权施工。

不为模板硬写心得。
